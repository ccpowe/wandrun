# 开始使用、聊天与富交互

App 基线：0.2.0；提交 `3226bed53ef73a60fc13d02fb440693979078077`；核对日期 2026-11-05。

## 心智模型

- Wandrun App 是与 Agent 聊天、查看成果和管理配置的手机入口；连接的服务器运行网关。文件、命令、网页操作发生在 Agent 选择的执行环境，不是直接操纵用户手机。
- 一个 Agent 是一组职责提示词、模型和能力选择；同一个 Agent 可有多个对话。新对话不会把其他对话完整历史带进来；跨对话稳定信息使用记忆。
- 新 workspace 默认只有显示名 `wandrun` 的引导与日常助手（技术 id `main`），选用 browser、skill-installer、wandrun-guide 与 Exa，没有团队成员。已有 workspace 不因升级自动替换配置；新建的其他 Agent 不自动继承这些技能或连接器。
- 用户可以直接交办具体任务，如查公开资料、整理一段文字、处理上传文件、浏览网页。不要要求新用户先学 MCP、填提示词或配置团队才能开始。

## 找入口

| 中文 | English | 位置 / 含义 |
|---|---|---|
| 对话列表 | Conversation list | 聊天左上菜单图标，打开对话抽屉 |
| 新对话 | New conversation | 聊天右上书写图标，或抽屉的新对话入口 |
| Agent | Agent | 抽屉上部：管理 Agent 列表，点一行看资料，不是直接开聊天 |
| 服务器 | Server | 抽屉上部：资源、执行环境与正在使用的浏览器页 |
| 搜索 | Search | 抽屉底部搜索入口 |
| 设置 | Settings | 抽屉底部齿轮入口 |

新对话页在输入框上方选择 Agent：最近使用的胶囊，或“全部 N / All N”打开全部 Agent 网格。选好后发第一条消息或添加附件才创建服务器上的对话。已有对话的 Agent 不在这里改归属；要和另一个 Agent 聊天，新开对话选择它。

点聊天顶部 Agent 名字 / 头像打开其资料。名称旁的子对话数量按钮独立打开协作卡片，不要教用户“长按名字切换成员”。

## 消息与附件

- 在输入框写目标并发送即可。工作期间也可以发新消息调整要求；发送会打断当前执行并交给 Agent 处理。停止按钮用于停止正在进行的工作，不等于删除对话。
- 输入框附件菜单支持相机、照片、视频、文件。用户选完等待上传；Agent 是否真正理解内容取决于所用模型和文件工具，不把“上传成功”说成“已经读懂音频或视频”。
- 用户发来文件后应实际获取和读取再回答；不要只根据名称总结。工具和附件的具体调用方式由运行时提供。
- Agent 的交付文件出现在消息附件中；点附件查看。支持的图片、文本、Markdown 可预览；其他格式用“下载文件 / Download file”或“分享文件 / Share file”交给系统 / 其他应用。大文本可能只预览前 1 MB，不等于完整文件被截断。
- 只有一串服务器文件路径不等于手机已收到文件；需通过消息附件交付。用户找不到附件时先核对是否真的发送，不让用户在手机找服务器绝对路径。

## 富交互消息

Agent 的消息可含步骤列表、表格、图表、表单与可点建议。用户无需自己写 JSON 或装插件。

- 只读列表 / 表格用来展示；可横滑的宽表格与卡片在消息内部浏览。
- 图表可以点选或按住拖动看数值，再点同一项取消；“数据 / Data”展开完整数据表。
- 表单先选择 / 填写，再点消息里的提交按钮；按钮文字由该消息定义，不假定一律叫“确定”。提交把值发回对话供 Agent 处理，不直接执行购买、授权等外部动作。发出后该组变只读并显示回执。
- 可点的后续建议 / 卡片会发送预先展示的内容；复制按钮只复制到剪贴板，不自动给 Agent 发消息。
- 出现“界面无法显示 · 查看原文”时可看原文并继续普通文字交流。不要假装不可用的控件已经提交成功。

## 搜索与历史

抽屉 › 搜索可以找 Agent、对话、消息和文件；这是本服务器上的内容搜索，不是互联网搜索。Agent 资料相关入口可限定该 Agent 范围。互联网资料可直接在聊天交办给有相应能力的 Agent。

抽屉中的既有对话可继续；长按对话可以重命名 / 删除。删除会停止该对话正在进行的工作，已交付文件仍留在服务器；不要把它当成“清空所有文件”或“忘记长期画像”。不承诺系统推送、离线执行或 App 本身常驻后台。
