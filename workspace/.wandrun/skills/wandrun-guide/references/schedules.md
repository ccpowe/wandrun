# 定时任务

App 基线：0.2.0；提交 `3226bed53ef73a60fc13d02fb440693979078077`；核对日期 2026-11-05。

## 创建：在聊天里让 Agent 做

用户可说：“按 Asia/Shanghai 时区，每天早上八点查公开新闻，选三条科技要闻，附来源链接。”。支持单次、每天、每周、五段 Cron。只在用户真正要创建且必要参数明确时使用 create_schedule；用户问“怎么设置”不等于已经创建，不能未经请求把示例落实成任务。

- 解释所需内容：什么时候、时区、具体做什么。用户的时区未知且影响预期时先问；不把服务器时区暗当用户所在地。可用“北京时间 / Asia/Shanghai”等明确表达。
- 定时归当前创建它的 Agent；到点会以该 Agent 新开对话，任务内容作为第一条消息，不继承本次聊天历史。完整要求要写进任务内容，不能写“照刚才那个做”。
- 以工具成功结果为准报告时间 / 时区和归属；没有回执不能说“设好了”。重复任务自动安排后续，无需每次执行后再创建一个。
- 需要网关在运行；关闭手机不等于关服务器。不能承诺服务器离线时仍执行、重启补跑所有错过任务，或手机一定收到系统推送。错过的时间会有未运行记录，不追补旧执行。

## 查看、暂停、修改、删除：在 App

路径：聊天顶部 Agent 名字 / 头像 › 资料 › **定时 / Schedules**。也可对话抽屉 › Agent › 选对应 Agent › 定时。

**此列表没有新建 ＋。** 创建在聊天中交办，不要把已移除的“新建定时”表单入口教给用户。

- 列表开关启用 / 暂停已有任务；暂停不删历史对话。已结束的单次不可重新启用。
- 点某项打开“编辑定时 / Edit schedule”；主表单“保存 / Save”，返回也会尝试保存改动。操作结果未确认时先等核对，别反复提交。
- 当前 Agent 只有创建定时的工具，没有查询 / 修改 / 删除已有定时的专用工具；已有任务管理引导用户到 App，不能猜 id 或声称已经暂停。

| 中文 / English | 含义 |
|---|---|
| 名称 / Name | 单行最多 64 字符，便于识别 |
| 要做什么 / Task | 未来对话的完整任务说明，最多 20000 字符 |
| 重复 / Repeat | 单次 / Once、每天 / Every day、每周 / Every week 或 Cron |
| 日期与时间 / Date and time | 单次 `YYYY-MM-DDTHH:mm` |
| 时间 / Time | 每天 / 每周使用 `HH:mm`；每周还需选星期 |
| 时区 / Time zone | IANA 时区，如 Asia/Shanghai；夏令时按该时区处理 |
| 启用 / Enabled | 只在保存后生效；不是“立即执行” |
| 最近运行 / Recent runs | 查看进行中、完成、失败、取消、未运行等真实记录，有关联对话可点开 |
| 删除定时 / Delete schedule | 确认后不再触发；已经创建的对话保留 |

五段 Cron 顺序为“分 时 日 月 星期 / Minute Hour Day Month Weekday”，不是六段含秒的格式。下次时间是已保存规则的结果，改草稿不等于网关排程已更新。没有运行记录不等于一定失败，也不要将未运行误报成任务成功。
