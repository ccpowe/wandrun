# 执行环境、服务器、连接与设置

App 基线：0.2.0；提交 `3226bed53ef73a60fc13d02fb440693979078077`；核对日期 2026-11-05。

## 三个概念，不要混用

- **服务器 / Server**：App 配对的网关，持有 Agent 配置、对话与服务状态。
- **执行环境 / Execution environment**：某 Agent 真正运行命令、处理文件、使用浏览器的位置。Local 是网关所在机器；Instabox 是服务器已能访问的已有云机器。
- **服务器与连接 / Server & connection**：手机保存服务器、配对、切换与断开的管理页；不是 CPU / 内存资源页，也不是云机器控制台。

文件与命令使用运行 Agent 的系统权限；Local workspace 不是 OS 安全沙箱。不要称它能任意控制手机，或说执行环境切换会自动搬家所有文件。

## 选择执行环境

路径：抽屉 › **Agent** › 选 Agent 看资料 › 右上铅笔 › **执行环境 / Execution environment** › 选 Local 或已有 Instabox › **完成 / Done** › 主表单 **保存 / Save**。

- 页面仅选择已有机器，不创建、删除、启动或暂停云机器。用户问“在 App 新建云电脑”时说明这里没有建机入口，不编一个“新建环境”按钮。
- 空闲时才可切换；工作 / 浏览器 / 文件传输 / 清理在途可能被网关拒绝。机器显示“运行中”不等于该 Agent 立即可切。
- 旧环境的文件不自动迁移；历史成果附件和新任务工作目录是两回事。切换前说明需要的文件应另行处理，不假称已经复制。
- Instabox 实际任务 I/O 可由运行时按需恢复 / 接入；只读看机器目录或服务器页不等于唤醒机器。列表缺少机器时核对服务配置 / 凭据，不私自换一个机器 id。
- 浏览器还需要该 Agent 勾选 browser 与环境正确接入；选一台机器不会自动授予全部 MCP 或成员能力。

## 看服务器资源

入口在 **对话抽屉 › 服务器 / Server**，不是设置首页一个新的资源按钮。

- 主机卡显示网关服务器运行时间、CPU / 内存、本机浏览器容量；不是把所有云机器容量加总。
- **执行环境 · N / Execution environments · N** 分组列出本机 / 云环境、状态、哪些 Agent 在用及浏览器数量。点一般环境行无管理操作，不提供启动 / 暂停。
- 环境很多时，部分已暂停机器收为 **另有 N 个已暂停 / N more paused**；点该行进入执行环境完整列表，可搜索与筛选 **全部 / All、运行中 / Running、启动中 / Starting、已暂停 / Paused、不可用 / Unavailable**。
- 页面下方按 Agent 分组列活动浏览器页；点页观看，左滑关闭对应任务全部页面。没有页时不代表连接故障。
- 读取失败保留旧信息，机器状态 / 在用者可能暂不可确认，不能把未知说成“没有”。服务器页只读查询不采样云端 CPU / 内存。

## 配对、切换或断开服务器

入口：抽屉 › **设置 / Settings** › 顶部服务器卡的管理 / 查看入口，进入 **服务器与连接 / Server & connection**。

- **添加服务器 / Add server** 后扫码，或手动输入服务器地址和服务器上生成的配对码。服务器端通过 `wandrun pair` 生成码；在 App 贴地址不是自动部署一个网关。配对码短时有效且一次使用，不让用户在聊天发送码。
- 已保存服务器可 **切换到这台服务器 / Switch to this server**，或设置卡 **使用这台 / Use this server**。各服务器的对话与 Agent 配置分开；切换不迁移数据。
- **备注名 / Nickname** 是手机本地显示名，不改服务器实际主机名。
- **断开这台服务器 / Disconnect this server** 移除手机记录和凭据并尝试取消配对，不停止远端网关、不删除服务器数据。再次连接需重新配对。
- 配对页 / 手机网络无法直达地址时，解释网络前提，不能把 loopback 地址当成手机可访问的远端地址；公网服务需合适 HTTPS / 私网保护。

## 模型、额度、外观

- **设置 › 模型 / Settings › Model**（实际页展示登录状态、订阅额度、模型目录和 Agent 用量）：**新建 Agent 默认模型 / Default model for new Agents** 只影响以后创建，不批量改变已有 Agent。
- 订阅额度来自服务器账户，不是手机电量或 Exa 的搜索额度。历史额度与当前登录状态不同；看到旧值不保证模型请求可用。Fast 可能多耗额度。
- 需要重登时按页内指引使用服务器专用 CODEX_HOME，停止网关、重登、重启；不要在聊天收账户凭据，也不擅自切到个人日常 Codex 目录。
- **设置 › 外观 / Settings › Appearance** 可改 **语言 / Language** 与 **颜色模式 / Color mode**，支持 **中文、English**，浅色 / Light、深色 / Dark、跟随系统 / Use system setting。外观设置只保存在此设备，不修改 Agent 的角色提示词；Agent 回复语言仍可通过聊天要求。
