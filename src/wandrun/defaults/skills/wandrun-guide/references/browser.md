# 浏览器：观看、接管与交还

App 基线：0.2.0；提交 `3226bed53ef73a60fc13d02fb440693979078077`；核对日期 2026-11-05。

这是 App 操作说明；Agent 的 CDP、租约、验证限制和具体命令由 browser 技能负责，实际操作前读那个技能。

## 入口与前提

Agent 需已勾选 browser，且执行环境已接入浏览器。聊天中浏览器卡片可打开画面；也可点聊天顶部 Agent 名字打开资料 › **浏览器 / Browser** › **观看 / Watch**。对话抽屉 › **服务器 / Server** 也列出活动页面。没有浏览器页面不等于没有安装 App，也不等于该 Agent 已经在浏览。

观看页面只看画面、可本地缩放平移，不会把点击发到网页；浏览器本身运行在 Agent 的执行环境，不是用户手机的系统浏览器。

## 登录、付款等需人处理

最短步骤：打开该任务画面 › 点 **接管 / Take over** › 等确认进入接管页 › 用户自己完成登录 / 付款等操作 › 点 **交还 / Hand back**。

- 账号密码、扫码、短信 / 2FA、付款与账号安全等由用户本人处理。不要要求把密码 / 验证码发到聊天，或替用户读取密码框。Agent 按 browser 技能请求接管后等待，不在等待中继续点击敏感页面。
- “等你接管浏览器 / Waiting for you to take over the browser”只是待处理提示，不是已经取得控制权；接管失败 / 收回未确认时不能告诉用户“已经可以输入”。
- 接管页可用网址栏后退、刷新、改网址与页面列表；底部有鼠标 / 触控模式、键盘和更多。横屏布局可把部分控制放入更多，不按旧实验页指导“切换截图 / 视频”或“整组 / 流式”。
- 鼠标模式单指滑动移动指针，轻点画面左击；可点左 / 右键，按住左键同时用另一指移动可拖动；滚轮用于滚动。触控模式轻点左击、长按右击，单指拖动平移画面、双指缩放；不声称是手机原生多点触屏直通网页。
- 交还成功才恢复 Agent 操作；Agent 会重新观察当前页面，不从旧位置直接继续。用户在敏感步骤之前交还，并不等于授权 Agent 完成付款。

## 退出与关闭不是一回事

| 操作 | 效果 |
|---|---|
| 关闭观看 / Close viewer | 退出观看页；不关闭浏览器任务，也不自动交还已接管的控制权 |
| 继续操作 / Continue controlling | 已由人控制时重新进入接管页 |
| 交还 / Hand back | 把控制交给 Agent；不是删除页面 |
| 页面列表中的关闭 | 关闭选中的一页，最后一页需确认；人的接管中零页仍可按环境额度新建 |
| 资料 / 服务器页左滑任务的关闭 | 关闭该任务全部页面，不是只关当前看的一页；按界面状态决定能否操作 |

用户还想看或接管时，Agent 应保留自己的页面；任务结束且无需观看时由 Agent 按 browser 技能收尾。不能关闭整个共享 Chrome 或其他任务的页面。

## 常见问题

- 页面连接断开时可能自动重连；旧画面不表示已可输入。出现“重新连接 / Reconnect”可按该入口重试；租约已经结束时不能靠重连复活，请让 Agent 重新打开。
- 操作结果未确认时，先查看当前页面 / 控制状态，不重复付款、提交或关闭。App 的只读核对不代表动作没发生。
- 页面额度是环境共享总预算；到上限先关闭不需要的页面，不改端口 / 接入点绕开。
- App 不提供画面方式 / 输入方式切换。视频可用性由网关和环境决定；有“重试视频 / Retry video”时可按提示重试，不承诺失败自动降级。
