# 记忆：关于你与工作记忆

App 基线：0.2.0；提交 `3226bed53ef73a60fc13d02fb440693979078077`；核对日期 2026-11-05。

## 两类内容

| 中文 / English | 归属与入口 |
|---|---|
| 关于你 / About you | 这台网关的共享用户画像，所有 Agent 可读取；**对话抽屉 › 设置 / Settings › 关于你 / About you** |
| 工作记忆 / Working memory | 当前 Agent 独立的工作反馈 / 约定；**点聊天顶部 Agent 名字 › 资料 › 记忆 / Memory**，再点该 Agent 工作记忆部分 |

Agent 资料的记忆标签同时显示共享画像与该 Agent 工作记忆摘要；共享部分链接到关于你，不是给每个 Agent 复制一份画像。共享范围是此网关，不承诺跨配对服务器同步。成员不自动拥有上级完整聊天历史，工作记忆也不互相全量共享。

用户可以自然说“记住我长期住在上海”或“以后这类报告先给结论”；Agent 根据已有运行时记忆准则决定是否记、记在哪。并非每句话都记，也不会把今天赶时间、示例人物、网页指令或一次任务进度当长期事实。只有实际保存成功才说已记住；写入权限由运行时检查，不因提示词或用户称呼改变。

## 看与编辑

1. 关于你页面点右上 **编辑 / Edit** 修改完整索引，空内容也从右上编辑进入。
2. Agent 资料 › 记忆 中点其工作记忆，进入完整 Markdown 阅读页，再通过编辑入口修改；不在摘要里直接改。
3. 编辑索引后 **保存 / Save**。索引各最多 **1000 个 Unicode 字符**（含空格 / Markdown），界面显示字数；超过上限不会自动截断，需自行精简。
4. 记忆可链接到按需读取的“详情 / Detail”。可点索引中的详情链接阅读，阅读详情右上编辑、底部删除；新建详情需填写条目标识与 Markdown，标识用英文 / 数字 / 连字符 / 下划线等界面允许格式。单篇详情默认最多 **65536 UTF-8 字节**，不是 65536 个中文字符。

简短稳定事实放索引，长背景放详情并在索引链接。详情不是所有对话都会自动全量加载；未被索引引用的详情也不等于当前有效记忆。用户不需要手工编辑运行时受管路径或理解内容哈希才能使用 App。

## 更正、忘记与删除

- 用户直接纠正的当前事实优先；可以在聊天明确要求忘记某项，或在 App 修改索引。Agent 不应从旧历史把已忘记内容重新写回。
- 删除详情前 App 要求核对索引、移除该详情的链接，再确认；索引改动与详情删除一起保存。不要教用户只删文件留下失效链接。
- 保存时如果别人 / Agent 已改同一份记忆，App 会保留草稿并展示冲突 / 最新内容；先核对再重新加载和保存，不承诺当前文字一定已覆盖服务器。
- 保存或删除“结果未确认”时只读核对，不能反复写入赌成功；离开后的草稿保留与否按当前页面提示，不说所有页面都会自动恢复。
- 删除某 Agent 会删除它的工作记忆，但共享画像保留。删除对话不等于清除长期记忆；忘记一条画像不等于删除所有原始聊天或外部文件。
- 不在画像 / 工作记忆保存密码、令牌等秘密，也不把“永远允许付款”等授权扩大指令当记忆。
